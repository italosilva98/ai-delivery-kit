Composição da squad

Quatro agentes em sequência, cada um só com as ferramentas do seu papel. Motor: Modo simulação / Claude CLI & Devin.

IDLE

Agente PM

Lê o pedido, o AI_CONTEXT.md e a árvore do repositório; define o nome da branch e o checklist de implementação.

FERRAMENTAS: nenhuma (só planeja)
IDLE

Agente Arquiteto

Mapeia o código só com ferramentas de leitura e devolve o plano arquivo por arquivo para o Coder.

FERRAMENTAS:
list_directory read_file search_code
IDLE

Agente Coder

Cria e altera os arquivos do plano dentro da pasta do app, sempre na branch da tarefa. Aciona o Devin CLI ou Claude CLI.

FERRAMENTAS:
read_file write_file replace_in_file
IDLE

Agente QA

Analisa o diff e roda um comando de validação permitido; se reprovar, devolve ao Coder (até 2 novas tentativas).

FERRAMENTAS: run_command

Comandos permitidos: npm run build • npm test • npx tsc --noEmit • pytest

Memória Viva (AI_CONTEXT.md)

Contexto lido pelo PM e Arquiteto antes de qualquer modificação.
